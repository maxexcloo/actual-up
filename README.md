# Actual Up

Actual Up synchronises Up transactions into Actual Budget. Development and
Kubelab deployment now live in
[mini-apps/apps/actual-up](https://github.com/maxexcloo/mini-apps/tree/main/apps/actual-up).

Use that directory for source changes, local usage, checks and deployment
configuration. Its [operator documentation](https://github.com/maxexcloo/mini-apps/blob/main/apps/actual-up/docs/operations.md)
describes credentials, persistent encrypted settings and recovery.

This repository retains the original history. The existing container image remains
available as the shared app's pinned dependency runtime; new app changes belong in
`mini-apps`.
